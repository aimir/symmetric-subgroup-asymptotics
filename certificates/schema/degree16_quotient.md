# Degree-16 quotient certificate contract

The file is a JSON object with the following fields:

| Field | Meaning |
|---|---|
| degree | Integer 16. All permutations act on the same sixteen labelled points. |
| source_generators | Nonempty list of permutations generating U. |
| image_generators | Corresponding proposed images, generating P. The two lists must have equal length. |
| kernel_generators | Nonempty list generating the proposed kernel N. |
| source_order, kernel_order, image_order | Integers 1024, 4 and 256, respectively; verified by enumeration. |
| target_orbit_types | Ordered list: C4 regular, D8 natural, D8 natural, D8 natural. Verified on the four consecutive blocks. |
| source_library_locator, image_library_locator | Informational catalogue labels. Neither is used as evidence by this verifier. |

Each permutation is a list of sixteen integer images of 1,...,16, with every
value occurring exactly once. The verifier converts to zero-based tuples.
Its multiplication is compose(x,y)[i]=x[y[i]], meaning x after y. Fields other
than those used above have no evidentiary role in acceptance.

## Verification argument

1. Enumerate the source, image and proposed kernel by repeated multiplication
   by their generators, starting at the identity. A finite permutation monoid
   generated this way is the generated group, since inverses are positive
   powers. Check the exact orders and source transitivity.
2. Starting with identity mapping to identity, propagate each proposed
   generator image over the complete source Cayley graph. Check agreement
   on EVERY edge, including edges reaching previously visited vertices.
   Agreement makes the map independent of the chosen positive word. It also
   gives f(x*s)=f(x)*f(s), hence a group homomorphism. Check its full domain,
   full image, exact kernel as a set, and the size of every fibre.
3. Compute the whole centre by commutation with all image generators. Check
   its order and that all its elements square to identity. The subgroup
   generated by generator commutators is central, so it is the full derived
   subgroup; verify its order. In this class-two group, generator squares and
   commutators generate P^2[P,P], the Frattini subgroup of the finite 2-group P.
   Check equality with the computed centre. Check that every target element
   has order dividing four.
4. Enumerate the actual point orbits and the full restricted projection groups.
   A degree-four group of order four with an element of order four is regular
   C4. A subgroup of S4 of order eight is a Sylow 2-subgroup, hence the natural
   D8 action. Check the ordered projection types and the strict inequality
   |P|<4*8^3. The C4 projection also ensures the exponent is exactly four.

The named finite-group facts and the checker algorithm will require checked
proofs when this certificate is consumed by Lean. A successful Python run is
an exact finite computation, not a substitute for those formal proofs.
