# Degree-16 nonbinary certificates

The alphabet is `../data/nonbinary_actions.json`; the normal records are the
gzip-compressed JSON-lines stream `../data/nonbinary_normals.jsonl.gz`.
Both use `schema_version: 1`. All subgroup and map data concern the original
permutation action, rather than only an abstract isomorphism type.

## Alphabet

Each of the 527 action records has:

* `action_id`, `catalogue_locator: [16,i]`, `degree: 16`, and `family`, one of
  `mixed`, `comparator`, or `head`;
* literal `generators`, exact `order`, and the number `normal_count`;
* literal `normalizer_generators` and `normalizer_order`, computed in the
  original symmetric group on 16 points.

A permutation is an array of exactly 16 integers, its images of points
1 through 16. Every such array must be a permutation. Empty generating lists
denote the trivial subgroup. Auxiliary map images instead have their stated
target degree: 8 for a comparator or `4 * model_rank` for a repeated head.
Auxiliary degrees do not replace the original degree or its normalizer weight.

The partition is 518 mixed actions with 8,807 normal entries; two comparator
actions with 175 entries; and seven head actions with 267 entries. The alphabet
also states the pinned TransGrp release and the 1,954-class degree-16 slice,
of which 1,427 classes are binary. Classification completeness is an external
mathematical premise, not a consequence of these numerical totals.

## One normal record per original action

Each JSON line has `action_id`, `classes`, `atoms`, `characters`, and `normals`.
All indices are one-based and refer only to lists in that same line.

`classes` contains literal conjugacy-class representatives, class sizes, and
`normal_closure`, an index into `normals`. `atoms` is the sorted list of all
distinct class normal-closure indices. Each normal entry has original
`generators`, `order`, `joins`, and a `certificate`. The `k`th join index names
the subgroup generated by that normal and the normal at `atoms[k]`.

This supplies an all-normal completeness certificate for arbitrary finite
groups. The verifier checks that the literal representatives lie in distinct
classes and that the sum of their class sizes, each recomputed as
`|U| / |Centralizer(U,g)|`, is `|U|`. It checks every class normal closure,
every join, normality and distinctness of the supplied subgroups, and the
presence of the trivial subgroup. Any normal subgroup is generated by the
normal closures of the conjugacy classes it contains. Consequently closure
under the displayed joins proves that no normal subgroup is missing. This
argument does not assume that the group is a 2-group and does not invoke
`NormalSubgroups` during verification.

## Actual irreducible characters

Each retained character has `degree`, a literal normal `kernel` index, and
`values` in the displayed class order. An integer value is stored directly.
Any other value is an object with a positive `conductor: n` and exactly `n`
`coefficients`, each a pair `[numerator,positive_denominator]`; it means

\[
\sum_{j=0}^{n-1}\frac{a_j}{b_j}\exp(2\pi i j/n).
\]

GAP performs all these operations in its exact cyclotomic field. The checker
matches the retained values to an actual irreducible character of the literal
group after matching the conjugacy classes. It also checks its degree and
literal kernel. A character's position in an `Irr` result is never part of
the certificate.

## The three certificate types

A `mixed` certificate gives `linear` and `general` lists of character indices.
Every designated linear character must have degree one; a general slot may
contain any irreducible. The intersection of all kernels must equal that exact
normal entry, and

\[
3^{64l}5^{64t}\le 2^{381}
\]

must hold. The tuple is fixed on the original group and descends faithfully to
its quotient by the retained kernel.

For the two comparator actions, the line also contains `comparator.kernel`
and `comparator.generator_images`. These define an onto homomorphism from
the original generators to the elementary abelian group generated by
`(1,2),(3,4),(5,6),(7,8)`, with kernel exactly the original derived subgroup.
Precisely the entire normal interval above that kernel has certificate kind
`comparator`; every other normal must pass `mixed`. Thus the quotient interval
is retained, not replaced by separate uncorrelated target choices.

A `head` certificate contains `central_preimage`, `central_rank`, `model_type`
(`A` or `S`), `model_rank`, and the images of every original generator. The
checker verifies that the central preimage modulo the original normal is the
whole elementary binary centre. Its quotient map must be onto the specified
repeated model and have exactly that preimage as kernel. The models have
independent Klein-four groups on `d` disjoint four-point blocks and a common
diagonal cyclic-three top (`A`) or symmetric-three top (`S`). Finally

\[
32\max(c,d)\le127
\]

is checked at the original width 16. No splitting of this central extension
is assumed or inferred.

There are 9,107 mixed normal certificates, 134 comparator-interval entries,
and eight central-head entries, totalling 9,249 literal normals. These types
are sufficient local certificates; they do not specify earliest global
ownership or independently prove the counting theorem.
